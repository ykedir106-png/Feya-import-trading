FEYA IMPORT & TRADING WEBSITE

How to Use

1. Open "feya_import_trading.html" in a browser.
2. The page is responsive for desktop and mobile.
3. Replace the Unsplash image URLs in the CSS with your own car/construction/ship images if desired.
4. Update phone, WhatsApp, email, address and translations directly in the HTML.
5. Upload the HTML file to GitHub/Vercel/Netlify or your normal hosting.
